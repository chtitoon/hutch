# hutch

**Your things, privately kept.**

Hutch is an iPhone app for keeping track of everything you own. It's end-to-end encrypted, so no one sees your inventory but you.

When you choose, you open a small door:

- 🤝 **Lend** things out, like the ladder to a neighbor or the folding table for a party
- 🏷️ **Sell** what you no longer need, when it's time

It exists because [every app I looked at](docs/context.md) made you trade privacy for sharing.

## The idea

Like the furniture it's named after: closed doors below, a few things on display. That idea runs through [the logo and the design](design/README.md), too.
