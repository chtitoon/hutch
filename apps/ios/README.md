# Hutch for iPhone

SwiftUI app. The Xcode project is generated from `project.yml` with XcodeGen (added in M0). Built and tested locally on the Mac with Xcode and the iPhone simulator; see [AGENTS.md](../../AGENTS.md).

Screens and behavior for each milestone are specified in [`design/`](design/): start with [`design/milestone1.md`](design/milestone1.md). The design canvas's source files are in [`design/canvas/`](design/canvas/) as a visual reference (D19).
